# Vidéo promotionnelle (projet en développement)

- `greliv-promo-16x9-1920x1080.mp4` et `greliv-promo-9x16-1080x1920.mp4` : non versionnées (fichiers lourds).
- `greliv-promo.srt` : sous-titres français synchronisés.
- `source/` : animation (`promo.tpl.html`), voix off (`voice.py`, voix libre Piper « fr_FR-tom-medium »),
  musique originale synthétisée (`music.py`), rendu image par image (`render.mjs`) puis encodage ffmpeg.

Les écrans montrés sont des captures du prototype (`e2e/ui-scenario.mjs` avec `CLEAN=1 SCALE=3`).
